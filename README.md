# Практическая работа №7

## Описание

Выполнена отладка консольного приложения на C#, обрабатывающего массив символов и формирующего строку.
Цель - изучить процесс пошаговой отладки и анализа выполнения программы в Microsoft Visual Studio.

## Ход работы

В программе выполнялся цикл, формирующий строку и выводящий сообщения.
С помощью отладчика анализировался процесс выполнения и изменение значений переменных.

## Использованные методы отладки
<img width="302" height="245" alt="image" src="https://github.com/user-attachments/assets/4eb27d70-971b-42d9-8871-cddaba869b09" />

В процессе тестирования применялись следующие методы:

* **Точки останова (Breakpoints)**
  Использовались для остановки выполнения внутри цикла `for`.

* **Пошаговое выполнение (F10, F11, Shift+F11)**
  Позволило проследить выполнение программы, переходить в методы и выходить из них.

* **Просмотр переменных (Autos, Locals, Watch)**
  Использовался для анализа значений переменных `letters`, `name`, `a[i]`.

* **Подсказки данных (Data Tips)**
  Позволили быстро просматривать значения переменных при наведении мыши.

* **Run to Click / Выполнить до курсора**
  Применялось для быстрого перехода к нужному участку кода.

* **Стек вызовов (Call Stack)**
  Использовался для анализа последовательности вызовов методов.

* **Перезапуск отладки**
  Использовался для повторной проверки работы программы после анализа.

## Результат

Освоены основные инструменты отладки Visual Studio.
Программа корректно выполняется, а процесс выполнения полностью проанализирован.
