# Практическая работа №7

## Описание

В ходе работы была выполнена отладка консольного приложения для вычисления чисел Фибоначчи в среде Microsoft Visual Studio.
Цель - найти и исправить ошибку с использованием встроенных инструментов отладки.

## Найденная ошибка

Программа возвращала неверный результат (3 вместо 5 для Fibonacci(5)).
Причина - неправильное условие в цикле `for`:

```csharp
for (int i = 2; i < n; i++)
```

Цикл завершался раньше, чем нужно.

Исправление:

```csharp
for (int i = 2; i <= n; i++)
```

## Использованные методы отладки

В процессе тестирования использовались следующие методы:

* **Точки останова (Breakpoints)**
  Позволили приостанавливать выполнение программы в нужных местах.

* **Пошаговое выполнение (Step Over / Step Into)**
  Использовалось для анализа работы цикла и перехода по коду строка за строкой.

* **Просмотр переменных (Locals)**
  Позволил отслеживать значения `n1`, `n2`, `sum` и определить момент возникновения ошибки.

* **Повторный запуск с анализом**
  Программа запускалась несколько раз для проверки гипотез и подтверждения исправления.

## Результат

Ошибка успешно найдена и исправлена.
Программа корректно вычисляет числа Фибоначчи.
