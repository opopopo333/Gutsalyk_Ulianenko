# Практическая работа №7

## Описание

Выполнена отладка консольного приложения, отображающего список галактик.
Цель - выявить и исправить ошибки с использованием средств отладки Microsoft Visual Studio.

## Найденные ошибки

1. **Неверный тип свойства**

```csharp
public object GalaxyType { get; set; }
```

Из-за этого выводилось имя класса вместо значения.

Исправлено на:

```csharp
public GType GalaxyType { get; set; }
```

2. **Опечатка в операторе switch**

```csharp
case 'l':
```

Из-за ошибки не обрабатывался тип "Irregular".

Исправлено на:

```csharp
case 'I':
```

## Использованные методы отладки

В процессе тестирования применялись следующие методы:

* **Точки останова (Breakpoints)**
  Использовались для остановки программы перед выводом данных и в конструкторе класса.

* **Пошаговое выполнение (F10, F11)**
  Позволило проследить выполнение кода и определить, что нужный блок `switch` не выполняется.

* **Просмотр значений переменных**
  Через наведение мыши анализировались значения `GalaxyType` и `type`.

* **Анализ поведения программы**
  Сравнивались ожидаемые и фактические результаты вывода.

* **Повторный запуск отладки**
  Использовался для проверки исправлений.

## Результат

Ошибки успешно обнаружены и исправлены.
Программа корректно выводит название, расстояние и тип галактик.
